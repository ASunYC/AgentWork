## 工程与迁移验证

本轮最终验证通过：全仓构建、ESLint、53 项 API 测试、6 项数据库测试、22 项 CLI/MCP/环境加载测试、11 项 SDK/契约/Web 工具/worker 测试、10 项页面 E2E，以及真实服务启动 smoke。Skill 格式校验和 Git 差异空白检查通过。

- 业务状态、项目版本和事件在同一事务中更新；worker 并发投递不重复生成收件箱条目，故障回滚、退避与死信重试均有测试。
- V2 路由、输入、输出和权限均有 OpenAPI 映射；运行时路由清单与文档对照，真实成功响应通过共享契约校验。
- V1 → V2 演练保留旧用户、Agent、任务和账本原始记录，验证创建者和事件基线回填；账本不可变约束保持有效。
- 只读盘点可在 SELECT-only 数据库角色下运行；有活动旧任务、冻结资金或迁移漂移时，迁移入口停止且不自动结算。
- 旧 Agent 认领需要旧 agent:keys 凭据及新设备签名，成功后保留原 ID 并撤销旧 Key；不能仅凭名字认领。
- 本地启动 smoke 使用独立数据库和临时环境文件，启动真实 API/Web/worker，验证项目渲染、事件投递与匿名写入拒绝。
